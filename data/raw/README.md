# data/raw

Downloads, saved unchanged. Never edit a file here; cleaned versions go in `data/clean/`.

The data files themselves are not committed (they are large, and case data must never be
pushed). Share them through the team drive. What **is** committed is one note per file,
named `<file>.md`, so anyone can download it again:

```
Source URL:
Downloaded on (YYYY-MM-DD):
Version / release:
Notes (subset box, years, anything changed in the request):
```

A note names no person: PJDSC's guidelines ask that the submission name no team, school or
member. When a script fetches the file, a `Script:` line names the command instead.
